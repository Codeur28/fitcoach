# FitCoach

Application web installable (PWA) de sport à la maison, du niveau débutant à avancé :

- programme personnalisé sur 8 semaines (âge, poids, taille, un ou plusieurs objectifs) ;
- 20 exercices au poids du corps avec animations des mouvements ;
- séance guidée avec minuteur, temps de repos, bips et vibrations ;
- nutrition : 7 régimes, 27 recettes, produits pas chers, liste de courses ;
- fonctionne hors-ligne, données stockées uniquement sur le téléphone.

Installation : ouvrir le site sur le téléphone, puis
- **Android (Chrome)** : menu ⋮ → « Installer l'application » ;
- **iPhone (Safari)** : bouton Partager → « Sur l'écran d'accueil ».

Les conseils donnés sont généraux et ne remplacent pas l'avis d'un médecin.
